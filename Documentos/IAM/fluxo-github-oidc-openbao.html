🔐 Federação Zero-Trust: GitHub Actions OIDC + OpenBao HA

Troca dinâmica de JWT efêmero por token de menor privilégio para leitura de segredos sem credenciais estáticas

Fase 1 JWT na Nuvem

O GitHub Actions gera um token OIDC assinado contendo as claims do repositório, branch e commit via id-token: write.

Fase 2 Injeção via SSH

O Runner conecta por SSH no nó público (200.18.99.87) e passa o JWT. O OpenBao não é exposto na internet.

Fase 3 Validação & JWKS

O OpenBao usa o tinyproxy para buscar as chaves do GitHub e emite um client token temporário (TTL: 15m, iam-reader).

Fase 4 Leitura Local

O script Ansible local lê secret/data/iam/* diretamente na rede privada .maas e provisiona a stack.
